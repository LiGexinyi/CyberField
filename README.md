# CyberField

**CyberField — 网络文化现象采集与传播演化研究工具**

一个面向中文互联网的网络文化数据采集与数字田野调查工具，旨在帮助研究者系统性地收集、整理和追踪网络热梗、流行话题及亚文化现象，为研究其传播机制、演化过程和背后的社会文化意义提供数据支持。

## 1. 项目背景

网络热梗和流行文化现象往往诞生于特定的社会情境，并通过不同社交平台快速传播、变形和衍生。

例如，“牛来”“奥德赛”“放生前额叶”等网络话题，其流行不仅涉及内容本身，也可能反映特定群体的情绪表达、文化认同、审美倾向与社会心理。

然而，相关讨论分散在微博、小红书、知乎等平台，具有信息碎片化、传播速度快、历史内容难以系统整理等特点。

CyberField 希望通过自动化数据采集和本地信息管理，为网络文化研究提供可追溯、可检索、可持续积累的原始材料。

## 2. 项目目标

本项目的核心目标是构建一个**以数据采集为中心的网络文化研究平台**。

主要包括：

1. **网络信息采集**：围绕指定热梗或话题，从符合访问规则的公开网络数据源获取相关文本。
2. **跨平台数据整合**：统一整理来自微博、小红书、知乎等平台的公开内容。
3. **本地资料存储**：保存文本、发布时间、来源平台、原始链接等信息，支持长期积累和检索。
4. **热梗溯源与传播追踪**：寻找可核实的早期传播记录，观察话题的兴起、扩散及衍生过程。
5. **数据筛选与可视化**：提供关键词搜索、时间排序、传播趋势和相关表达统计。
6. **人工田野研究支持**：允许研究者阅读原始材料、添加标签和观察笔记，自主分析网络文化现象背后的社会意义。

项目主要负责信息采集、整理和呈现，不以自动生成社会学结论为核心目标。

## 3. 主要功能规划

| 模块 | 功能 |
| --- | --- |
| 数据采集 | 关键词检索、分页采集、增量更新、断点续采 |
| 数据管理 | 本地存储、数据清洗、去重、来源记录 |
| 话题管理 | 创建调查项目、管理关键词及衍生表达 |
| 传播追踪 | 早期记录检索、时间线构建、热度趋势展示 |
| 资料检索 | 全文搜索、平台筛选、时间范围筛选 |
| 田野笔记 | 人工标注、收藏材料、记录观察与研究假设 |
| 数据导出 | CSV、JSON 等格式 |

## 4. 技术栈

- **Python**：主要开发语言，实现数据采集和处理。
- **Requests / BeautifulSoup**：处理获准访问的公开网页及接口数据。
- **Pandas**：数据清洗、去重和统计。
- **SQLite**：本地数据库，保存采集结果及元数据。
- **Streamlit**：构建交互式研究界面。
- **Plotly**：展示传播时间线和数据统计图表。
- **Git**：项目版本管理。
- **OpenCode**：AI 辅助编程、调试与测试。

## 6. 数据来源与使用原则

项目主要关注微博、小红书、知乎等中文社交平台。

数据采集以公开且获准访问的内容、官方接口及合法获得的数据集为基础，遵守相关平台的访问规则和速率限制，不绕过登录权限、验证码及其他访问控制。

项目优先保存研究所需的文本和来源信息，尽量减少个人身份信息的采集。所有数据默认保存在本地，不主动公开包含个人信息的原始资料。

对于热梗溯源，系统区分“当前数据中最早检索到的记录”和“真实起源”，避免将不完整的采集结果误认为完整传播历史。
