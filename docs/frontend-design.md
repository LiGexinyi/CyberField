# CyberField 前端与数据口径

设计依据：https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md

## 设计计划与复核
面向网络文化研究者，首要任务是检索样本并核对原文。采用阅读工作台，而非营销首页。
- 颜色：雾白 #F6F8FB、纸白 #FFFFFF、深蓝 #19334C、次级文字 #637487、青色 #147A7A、分隔线 #DCE4EC。
- 字体：标题用本机宋体，正文用微软雅黑/苹方；英文品牌用 Georgia。无字体下载。
- 布局：左对齐。顶栏和搜索常驻页面上部，下方筛选、结果、阅读详情三列；分析替换后两列。
```text
品牌                         本地资料库
标题                         刷新
[             关键词检索             ]
资料浏览 | 观察与分析              数量
筛选     结果列表                阅读详情
```
复核后去掉了装饰性指标卡和无数据依据的情绪百分比，保留原文核对作为主要交互。手机布局改为筛选在上、结果与详情纵向排列。焦点可见、来源使用安全链接、原文以 textContent 输出。

## 数据口径
- 影视条目不是用户帖子。导演/年份留在 extra，不能计入作者或每日发帖数；旧库读取时隔离旧误填字段，原值仍在磁盘并在返回值 extra 中可查。
- 固定时间格式为北京时间 YYYY-MM-DD HH:MM:SS。无时区的完整日期按北京时间解释；秒/毫秒及带时区日期转换；年份、相对时间、非法日期不猜测。原时间保留。
- 互动快照存储在 post_observations，UTC observed_at 指本地入库观察时刻，不是平台发布时间。重复帖子不重复插入主表，但每次保留快照与搜索关键词。旧库没有保存过的指标无法补造。
- MediaCrawler 比较前后记录多重集合，仅返回新增观测并截断 limit。相同内容追加可以识别；完全原样覆盖、没有新增输出时保守返回空，不声称拿到新结果。不要同时运行外部 MediaCrawler 向同一目录写结果；若需要并发，应配置独立输出目录。
- 图表是当前筛选样本的发帖日期分布，不是全网热度或采集量。豆瓣条目和未知日期排除。大量日期按月汇总；无样本月份不能解读为全网零讨论。
- 重复短语是简单正则片段的文档频次，不等于中文分词、情感或主题模型。群体观点、情绪比例、演化解释不生成虚假占位数。

## 验证
离线假源、独立临时SQLite库、旧库字节不变核对；桌面1440px与手机390px浏览器检查。界面读取真实数据，不上传数据到任何远端。
